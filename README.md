# Galaxy Mind private Umbrel community app store

One app: `galaxymind-pusher` (code: GalaxyMind21/gm-umbrel-pusher). Image is pinned by `@sha256` digest; there are
no mutable tags here, so the Umbrel only changes when this repo changes and the owner clicks Update. Every change to this repo
is a code path onto the Umbrel: PRs only, log in /workspace/umbrel/config-history/CHANGES.log before installing/updating.
